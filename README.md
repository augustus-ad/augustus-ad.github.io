# AUGUstus project page

Static project page for GitHub Pages. Serve the repository root; no build step is required.

For local preview, run `python3 -m http.server 8765`, then open http://127.0.0.1:8765/.

`index.html`, `media.css`, and `gallery.js` contain the page. `assets/` contains the displayed figures, tables, videos, posters, logos, and icons.
